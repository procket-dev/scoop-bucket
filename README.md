# Procket Scoop bucket

```powershell
scoop bucket add procket https://github.com/procket-dev/scoop-bucket
scoop install procket
procket setup
```

[Procket](https://procket.dev) records the prompts behind your commits. This
bucket is updated automatically with each release; see the
[install guide](https://procket.dev/install) for other ways to install.
